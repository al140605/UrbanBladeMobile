# UrbanBlade Mobile — Rediseño visual v3

La interfaz Android toma como base el tema **Sastrería Nocturna** del frontend web.

## Tokens principales

- Fondo: `#0A0A0A`
- Tarjeta: `#161616`
- Superficie secundaria: `#1F1F1F`
- Línea: `#2C2C2C`
- Oro: `#D4AF37`
- Oro tenue: `#A8842C`
- Texto: `#F2F2F2`
- Texto secundario: `#9C9C9C`

## Cambios

- Sistema de diseño reusable en `ui/components/UrbanComponents.kt`.
- Tipografía, shapes y paleta actualizados.
- Login/registro/recuperación con identidad UrbanBlade.
- Dashboard premium con KPIs y accesos rápidos.
- Citas con resumen, estados y tarjetas de agenda.
- Reserva guiada por pasos.
- Catálogo de servicios y barberos con imágenes.
- Tienda con carrito persistente durante la sesión de pantalla.
- Pedidos, pagos, perfil y módulos secundarios rediseñados.
- Bladebot con burbujas de chat.
- Navegación inferior alineada a la estética de la web.

El backend sigue siendo la autoridad para autenticación, roles, precios, stock y reglas de negocio.
