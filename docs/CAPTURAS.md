## Selección editorial

El README utiliza estas dos vistas para mostrar Android sin exponer sesiones personales. Se descartaron de la portada imágenes con superposiciones personales, datos de cuentas, cobros o escenarios de error. Las comparaciones de diseño, propuestas y materiales de Play permanecen en sus carpetas como evidencia de su trabajo original.

Antes de añadir o sustituir una imagen, registrar commit, fecha, variante y entorno; utilizar datos sintéticos y revisar notificaciones del sistema, correos, identificadores, recibos y cualquier credencial visible. No presentar una propuesta como implementación ni una captura antigua como validación de la versión actual.
